# 简作 · Android

原生 Android Studio 工程，使用 Java 17 和 Android View。**同一个 APK 支持安卓手机和安卓平板**，最低 Android 8.0（API 26）。应用运行不依赖第三方库；本地写作无需联网或存储权限，DeepSeek AI 续写使用联网权限。

## 手机与平板

按当前窗口的可用宽度适配，支持横竖屏、分屏和调整窗口大小：

| 窗口宽度 | 布局 |
| --- | --- |
| 小于 600 dp | 文稿列表 → 编辑页；工具栏或系统返回回到列表 |
| 600–1099 dp | 文稿列表与编辑器并排；通过列表上方切换笔记本 |
| 1100 dp 起 | 笔记本侧栏、文稿列表、编辑器三栏 |

专注模式隐藏列表和侧栏。旋转或重建页面后保留当前文稿、预览模式、专注模式、光标和滚动位置。

## 功能

- 标题与正文使用原生 EditText，支持中文输入法、文本选择和系统编辑菜单。
- 文稿、灵感、日记三个默认笔记本，可新建／重命名自定义笔记本；标题、正文、卷名和标签搜索，收藏与四种排序。
- Markdown 预览支持标题、段落、粗体、斜体、链接、引用、列表、代码块和分隔线；另支持任务列表和基础表格；图片、公式、HTML 不渲染。
- 创建副本、移动笔记本、废纸篓恢复；彻底删除需要确认。
- 通过系统文件选择器导入 UTF-8 Markdown / TXT（支持多选，单篇最多 2 MB），导出 Markdown / TXT。
- 停止编辑约 450 毫秒后原子保存；离开前台立即完成写入；损坏的文稿库不会被覆盖。
- 中英文混合字数、字符数、阅读时间、每篇字数目标。
- 衬线 / 系统 / 等宽 / 导入 TTF 或 OTF 字体、14–26 sp 字号、4–18 dp 行距、跟随系统 / 浅色 / 深色外观。
- 外接键盘：Ctrl+N 新建、Ctrl+S 保存、Ctrl+P 预览、Esc 退出专注。

## 1.1.0 写作功能扩展

参考用户提供的纯纯写作 APK 功能入口，加入以下独立实现。逐项检查依据、实现差异和未接入服务见 [功能对照报告](../Docs/PureWriter-analysis.md)。

- 自定义笔记本、卷名、标签、四种排序、章节上移／下移，按章节顺序合并成书。
- 每篇最多 40 个历史版本，可查看并恢复，或恢复为独立副本；批量替换／排版前保留旧内容。
- 查找替换：大小写、正则、上一处／下一处、当前篇／当前笔记本／全库范围，执行前确认。
- 一键排版预览、Markdown 大纲定位、只读开关、第二编辑器、灵感速记与写作模板。
- 快捷撤销重做、成对符号、日期／缩进／待办、自定义快捷输入；成对标点补全、动态缩进和打字机模式。
- 每日新增字数与 28 天格子、关键词检查、系统 TTS 朗读、屏幕常亮、设备密码锁。
- PDF、PNG 长图、HTML、ZIP 批量导出；ZIP 内 Markdown / TXT 勾选导入；复制与系统分享。
- .jzb 整库备份（含历史和元数据）、SHA-256 完整性校验、预览后合并；本机自动保留最近 24 份旧库快照。

常用入口在文稿列表「更多」、编辑页「更多 → 写作工具／更多导出与分享／调整章节顺序」，以及「写作设置」。Ctrl+F 查找，Ctrl+Z／Ctrl+Shift+Z 撤销重做。关闭并重新打开会恢复当前文稿，记忆每篇光标和滚动位置。

PDF 和 PNG 从 1.9 起可选 Markdown／原文排版。长图上限 16,000 像素，PDF 上限 1,000 页。ZIP 解压总量和 .jzb 恢复上限 64 MB；ZIP 每篇上限 2 MB、最多导入 1,000 篇。字体上限 32 MB。TTS 要求设备有相应语音；设备锁要求先设置系统密码，且不属于文件加密。

## 1.2.0 本地功能补齐

- 历史版本详情中「与当前版本对比」：按行标记增加／删除；大篇幅按块比较，截短预览不影响原文。
- 查找替换中「勾选要替换的结果」：逐条选择，确认后保留旧版本；列表可按相关度排序，设置可启用多关键词同时匹配。
- 系统文件选择器支持多选 Markdown / TXT；与 ZIP 共用导入预览，可勾选、预览正文、改名及调整顺序。
- 「写作工具」加入段落上移／下移；设置中可启用整段缩进退格、换行逗号转句号。
- 「更多导出与分享」加入 DOCX、EPUB、富文本复制，HTML 升级为基础 Markdown 排版；合并成书可选 Markdown／DOCX／EPUB。
- 「文稿统计」加入不含空白字符数、汉字数和当前卷／全书计数；「每日统计」加入每日目标、四级热力图和年度回顾。
- 「管理笔记本 → 笔记本 → 添加到桌面」创建系统快捷方式，重命名同步更新，删除空本后禁用入口。

DOCX／EPUB／HTML 支持标题、粗斜体、引用、代码、列表、任务和基础表格；EPUB 有标题目录，DOCX 中的链接保留名称与网址文字。图片、公式、复杂嵌套及原始 HTML 不做富渲染。PDF／PNG 的 Markdown 排版见 1.9 说明。导入最多 1,000 篇，总量 64 MB、单篇 2 MB；逐条替换预览最多 2,000 处。

## 1.3.0 分卷与章节整理

- 「文稿列表 → 更多 → 管理分卷」可创建空卷、改名、调整卷顺序、整卷移到其他笔记本、整卷回收／恢复，以及解散分卷保留文稿。整卷移动包括废纸篓中的章节；目标有同名卷时会提示先改名。
- 「目录与筛选」可启用按卷折叠目录，并按分卷和精确标签交叉筛选；搜索继续作用于筛选结果。目录记忆折叠状态，常驻显示全书和当前筛选范围的字数。
- 长按章节右侧 ≡，拖到另一章前或卷标题中；自动切到手动顺序。章节上移／下移在同卷内进行。拖动当前可见目标，长列表也可使用章节移动菜单。
- 「文稿列表 → 更多 → 批量章节编号」支持 `{n}` 序号、`{title}` 原标题、自定起点、数字补零、移除旧“第N章”前缀，并可限定单卷。先预览再确认，跳过只读与废纸篓，改名前保留历史。
- 成书导出按“未分卷 → 分卷顺序 → 卷内手动顺序”排列；每卷标题只输出一次。空卷只保存在整库备份中，不输出空正文。

目录为笔记本／分卷／章节三级，不支持任意嵌套文件夹。分卷使用独立 ID，改卷名不改变章节关联；组织操作不会改写正文。

## 1.4.0 双稿对照与长篇整理

- 「文稿菜单 → 写作工具 → 第二编辑器」打开常驻双稿。宽窗口（600 dp 起）左右排列，窄窗口上下排列，占用整个写作区域。主稿和参考稿都可编辑标题／正文、独立切换 Markdown 预览和选稿；同一篇不能同时放进两侧。
- 点击各侧的「主稿／参考稿」或直接进入正文来激活该侧，顶栏文稿菜单和底部快捷输入作用于当前激活稿。只读稿显示阅读区，编辑工具仍受只读保护。
- 顶栏可设置主稿占比 40%／50%／60%，以及按相对进度联动滚动。关闭联动时各自滚动；两篇的光标、选区和位置分别记忆。返回键／左上角关闭双稿，回到主稿；正常关闭再打开应用会恢复双稿选择。
- 两篇均沿用原子保存、最多 40 个历史版本和每日新增字数统计。界面重建不丢正文，导出／查找替换等操作使用激活稿。
- 「调整章节顺序」增加「在此章前新建／在此章后新建」，继承笔记本、分卷和标签，切到手动顺序，原章正文不改写。
- 拖动章节到目录顶部／底部附近会自动滚屏，可移入原先看不见的卷。松手、取消或离开目录后停止滚动。

联动按两篇各自的滚动比例对应，不进行段落语义匹配。双稿选择、比例、联动和阅读位置保存在本机界面设置，不进入整库 .jzb。

## 1.5.0 快捷输入与选区统计

- 「写作工具 → 快捷输入栏」或「写作设置 → 快捷输入栏布局与内容」管理全部内置／自定义快捷项。可选 1–3 行，每行左右滑动；勾选显示、长按 ≡ 拖到目标项之前，或点 ≡ 上下移动／移到首尾。
- 自定义项用独立名称和正文输入框，支持直接换行、编辑和删除；最多 30 项，名称最多 24 个字符，插入内容合计 8,000 字符。旧版 `名称|内容` 设置自动读取，原有 `\\n` 换行含义保留；旧名称超过 24 个字符时缩短名称，插入内容完整保留。新界面直接输入的反斜线按字面插入。
- 调整过程中仅修改配置副本，最后点「保存」才生效；「取消」丢弃本次调整。「恢复默认布局」恢复内置按钮和单行排列，保留自定义项及其内容。
- 状态栏计数可点击切换混合字数、含空白字符数、不含空白字符数或汉字数；也可在写作设置选择。编辑正文选中文字后显示「选中／全文」计数，单稿和双稿均使用当前激活正文。
- 字符按 Unicode 码点计数，补充汉字和表情各为一个码点，不等同于视觉字形数量。文稿目标、目录和每日统计继续使用混合字数，状态栏单独注明目标口径。

反向选区同样支持计数、重建／正常重开恢复，以及快捷输入的替换和成对符号包裹。读屏会读出当前计数和切换提示。

快捷栏和统计口径保存在本机设置，不进入整库 .jzb。本轮库格式仍为 3，兼容 1.3／1.4 的整库备份。

## 1.6.0 写作时长与统计恢复

- 修改文稿标题或正文后开始记录时长，停笔最多继续计入 60 秒。离开前台、其他窗口取得焦点、重建界面、切换稿件／预览／只读时暂停，下次实际修改才重新开始。主稿与参考稿共用一个计时器；速记、导入和批量操作不启动计时。
- 「每日统计」显示今日／累计时长，点击日期查看当天字数和时长；「年度回顾」显示全年、每月时长和记录时长的天数。新增字数天数与连续天数仍按正文正向字数变化计算，标题修改或删改可有时长而无新增字数。
- 使用经过时间计量时长，按本地日期拆分跨午夜区间；系统时间／时区变化在下次编辑时更新归属，不放大已记录时长。每 10 秒及编辑、暂停时结算，沿用自动保存；进程被强制结束可能丢失尚未保存的最后一段。
- 写作设置可关闭「自动记录写作时长」，保留已有记录；开关是设备设置，不进入备份。
- .jzb 包含每日时长。恢复预览可选「同时恢复每日字数和写作时长」，默认不勾选；勾选后同日分别取较大值，重复恢复不累加，适合本机备份恢复，不用于汇总不同设备。

库格式升级为 4，可读取格式 1／2／3；旧库不推测历史时长。升级后的库和备份需 Android 1.6.0 或更新版本读取。首次保存前沿用旧库自动快照，请保留升级前的外部备份。

## 1.7.0 文件夹与系统分享导入

- 「文稿列表 → 更多 → 导入文件夹」通过系统选择器扫描 Markdown / TXT，包括子目录。根目录文稿进入当前笔记本，第一层子文件夹作为笔记本，更深层合并到对应笔记本；保留同名文稿为独立篇章，不建立分卷。按文件名稳定排序，隐藏文件／目录和非文本附件跳过。
- 目录扫描使用独立队列，不阻塞文稿保存。扫描最多 5,000 个条目，最多导入 1,000 篇、总正文 64 MB、单篇 2 MB；重复／循环文档引用、无权限、无效 UTF-8 或超限会中止整批，确认前不写入文稿库。目录扫描和预览支持旋转；预览中已保存的标题、顺序和勾选保留。详情窗口尚未点「保存」的修改不保留；进程被系统终止后需重新选择来源。
- 在其他应用分享纯文本或 Markdown / TXT 文件到简作，或从系统文件应用用简作打开文本文件，均进入同一导入预览。支持多文件分享和重复 URI 去重，不自动修改原文件；接收的 MIME 类型为 `text/plain`、`text/markdown`、`text/x-markdown`，文件需有 `.txt`、`.md` 或 `.markdown` 扩展名。分享文字使用主题作为标题，无主题时使用当前界面语言的默认标题（中文为「分享的文字」）。
- 外部分享复用已有主页面，避免创建两份可写文稿库；启用设备锁时，解锁后才处理分享内容。
- 导出正文、成书、ZIP 和整库备份先在后台写入应用私有临时快照，页面恢复只保存快照 ID，避免大文稿占满系统状态。文件选择器中的旋转／进程重建可继续导出；完成或取消后清理，遗留快照在下次导出时清理超过七天的文件。若系统清理缓存，需重新发起导出，原文稿不受影响。
- 修复小屏导入预览长标题导致勾选项被裁切，以及导入后沿用旧标签／分卷筛选隐藏新文稿的问题。

库格式保持 4，不改变已有文稿和备份格式。完整检查及剩余功能范围见 [未完成功能检查记录](../Docs/Android-unfinished-audit.md)。

## 1.8.0 扫描控制与跨来源找回

- 文件夹扫描显示已检查条目、已读文稿和容量；「取消扫描」或系统返回立即放弃本次候选，不会导入部分文稿。旋转继续显示进度，取消后迟到的结果不会弹出。文件名中的连续数字按数值排序，例如第 2 章先于第 10 章，支持超长数字和补零名称。
- 「备份与恢复 → 按关键词找回文稿内容」同时搜索当前文稿、废纸篓、历史版本及最近 24 份本机自动快照，按标题／正文进行不区分大小写的字面匹配。相同文稿 ID、标题和正文去重，显示来源、笔记本、内容时间及匹配附近片段，可查看完整正文并「保存为新文稿」。原文和来源快照保持不变；副本只恢复标题、正文和笔记本，不复制收藏、卷、标签或整段历史。
- 搜索在独立线程执行，最多显示 200 个版本，单份快照上限 64 MB，总读取预算 256 MB。损坏、失效或超限快照会跳过并提示；关闭窗口取消搜索。旋转、退出或应用锁定会关闭找回窗口，需要重新输入关键词。

取消会请求系统文件提供方中止查询并关闭读取；提供方若忽略取消，底层操作可能继续等待，但结果已丢弃且不阻塞文稿保存。后台扫描最多两路，均被提供方占用时提示稍后重试。库格式保持 4；进程终止后仍需重新选择导入来源。

## 1.9.0 PDF 与长图 Markdown 排版

- 「更多导出与分享 → 导出 PDF／导出长图 PNG」先选择「Markdown 排版」或「原文排版（保留标记）」，再选择保存位置。默认 Markdown；选择随导出快照跨保存选择器和旋转保留。原文模式保留 Markdown 标记、空行及代码围栏；文稿本身不改写。
- Markdown 模式支持六级标题、粗斜体、行内代码、带网址的链接、列表、任务、引用、代码块、分隔线和最多八列的基础表格。图片、公式、原始 HTML 和超宽表格以文字保留，不加载网络资源；不支持复杂嵌套、合并单元格或按表格分隔行指定列对齐。
- PDF 为 A4，按文字行分页，标题尽量与后文同页。表格跨页重复普通高度的表头；单行过长时按各单元格的文字行继续，短单元格不重复。超长表头超过正文区三分之一时不重复，避免挤占内容。代码／引用跨页保留底色。页脚显示页码。
- 长图宽 1080 px、高度最多 16,000 px，PDF 最多 1,000 页，字体沿用所选正文字体，代码使用等宽字体。导出字体大小和边距固定，保持输出一致；罕见字和表情的字形取决于设备字体。
- 先在私有缓存完成 PDF／PNG 排版，再写入所选目标；超限或排版失败不会清空已有目标文件，临时文件结束后清理。最终写入阶段若存储提供方失败，仍可能留下不完整目标，需要重新导出。

库格式保持 4；Markdown／TXT 导出仍为原始正文。

## 1.10.0 配色主题与横线稿纸

- 「写作设置」新增「配色主题」与「稿纸样式」：简作、山林、海雾、玫瑰、黑白五套内置配色，各有浅色／深色版本，沿用「外观」的跟随系统／浅色／深色选择。默认仍为原有简作配色；未知主题 ID 回退到默认。
- 可选空白或横线。横线跟随正文原生文字行、自动换行与行距，在正文文字下绘制，并延续到空白输入区；只绘制可见范围，不按整篇万行文稿逐行遍历。适用于单稿、双稿、原文只读和废纸篓阅读；Markdown 预览不显示横线。
- 设置窗口内实时预览配色、明暗模式和稿纸。点「完成」同时保存全部设置，取消不修改偏好；保存后界面重建／正常重开保留主题、稿纸及编辑选区。未保存的设置窗口不会跨旋转保留。
- 原生控件强调色、窗口背景随主题更新；强调色按钮和每日统计格子根据底色选择黑／白文字，避免深色主题的浅色按钮仍使用白字。
- 主题、稿纸均为本机偏好，不进入 .jzb，不修改正文、历史、字数或写作时长；PDF／PNG／HTML／DOCX／EPUB 继续使用各自固定导出样式。

库格式仍为 4，未增加运行时依赖或权限。自定义颜色、背景图片、稿纸间距设置与主题文件导入／导出尚未提供。

## Android Studio 打开

1. 在 Android Studio 中选择 **Open**，打开仓库中的 `Android` 目录。
2. 使用 Android Studio 自带的 JDK（或 JDK 17 以上），等待 Gradle Sync 完成。
3. 在 SDK Manager 安装 **Android SDK Platform 37** 和 **Build Tools 36.0.0**。
4. 选择 `app`，选择安卓手机或平板模拟器 / 真机，点击 Run。

工程使用 Android Gradle Plugin 9.4.1、Gradle 9.6.0，已在本机 Android Studio 2026.2.1 配套环境构建。Gradle Wrapper 和分发包 SHA-256 已包含在源码中。首次同步需要访问 Google Maven、Maven Central 和 Gradle 分发服务。`local.properties` 是本机 SDK 路径，不提交到 Git。

## 构建与安装

从仓库根目录运行：

```sh
# 构建可安装的调试 APK，同时运行单元测试与 Lint
bash Scripts/build_android.sh

# 已有 Java 和 Android SDK 环境时，也可直接运行
cd Android
./gradlew assembleDebug testDebugUnitTest lintDebug

# 连接手机或启动模拟器后运行设备测试
./gradlew connectedDebugAndroidTest

# 安装到连接的设备
adb install -r app/build/outputs/apk/debug/app-debug.apk
```

打包脚本将调试 APK 和校验文件放到 `Build/Android/`。手机和平板使用同一个 APK。

发布包可用 `./gradlew assembleRelease` 构建；正式分发需在 Android Studio 的 **Build → Generate Signed App Bundle or APK** 中使用自己的发布密钥签名。不要将发布密钥或密码提交到仓库。

## 本地数据

文稿库为应用私有目录 `files/library.json`，采用 `AtomicFile` 写入。首次运行创建三篇示例文稿；删除所有文稿后不会重新生成示例。

安卓与 Apple 版本各自保存本地数据，没有云同步。通过 Markdown / TXT 导入、导出交换正文。导出的标题用作文件名，文件内容只包含正文，不包含笔记本、收藏和时间等元数据。内部 JSON 时间格式与 Apple 版本不同，不应直接替换彼此的文稿库。

库格式 4 可读取格式 1／2／3，并在下次保存时升级。旧卷名自动迁移为独立分卷，正文、历史和手动章节顺序保留；升级后的库与备份须用 1.6.0 或更新版读取。整库 .jzb 含历史、笔记本、分卷（包括空卷及顺序）、标签、收藏、只读、速记和统计；恢复时为文稿创建新 ID 并合并，重复导入会得到副本；每日统计默认不合并，可选择按日期取较大值恢复字数和时长。自定义字体和界面／安全设置不包含在 .jzb 中。

卸载应用会删除本地文稿和自动快照；重要内容请先导出 .jzb 或 Markdown / TXT。应用关闭系统自动备份和设备迁移，保留手动导出方式。

## 1.12.0 DeepSeek AI 续写

1. 在「写作设置 → DeepSeek AI 设置」填写自己的 API Key；「测试连接」读取可用模型列表，不生成文字。默认使用 `deepseek-flash`，模型 ID 可改为连接测试返回的其他 DeepSeek 模型。
2. 在文稿菜单「写作工具 → AI 续写」填写可选续写要求、选择短／中／长篇，然后点击「生成 / 重新生成」。空文稿必须填写要求。生成采用文稿本身的语言和风格；界面语言不会强制改变正文语言。
3. 结果先进入可编辑预览，确认后插入光标位置；选中文字不被替换，预览模式在文末续写。可复制、取消、重新生成。插入保留原文历史，当前可编辑页面支持即时撤销；生成时不会增加人工写作时长或每日打字字数。

请求直接通过 HTTPS 发送至 `https://api.deepseek.com/chat/completions`，不经过自建代理。发送的是标题（最多 300 UTF-16 单元）、光标前约 12000／后 2000 UTF-16 单元及最多 2000 单元的续写要求，不上传文稿库、历史、其他篇目或 Key 以外的配置。句末缺少换行时补上段落衔接；具体文本仍由用户在预览中确认。接口规则见 [DeepSeek 官方文档](https://api-docs.deepseek.com/api/create-chat-completion/)。

API Key 使用 Android Keystore 的 AES-GCM 密钥在本机加密保存，与文稿库分开，不进入 .jzb、自动文稿快照或系统备份；可在 AI 设置中移除。设置页隐藏 Key 并禁止截图，保存后再次打开不回显 Key；留空表示保留现有 Key。用户提供的测试 Key 未写入源码、文档或安装包。

费用由用户的 DeepSeek 账号承担；超时／取消后服务商仍可能计费。请求不自动重试，生成过程可以取消；旋转／重建会关闭 AI 窗口并取消本次请求。接口鉴权失败、余额不足、限流、超时、网络故障、内容不可用及输出截断分别有中英文提示。原文变化、被回收／删除或变成只读后，旧结果不能覆盖原文，可复制后重新打开续写。

本轮为安卓主动续写，未包含实时副驾驶、标题建议、校对、对话、Apple AI 或云同步。文稿库格式保持 4。新增代码集中于 `DeepSeekClient`、`AiContinuation`、`AiKeyStore`、`AiDialogs`；完整测试及实际接口结果见 [验证记录](../Docs/Android-validation.md)。
