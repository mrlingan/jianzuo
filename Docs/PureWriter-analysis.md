## 边界与数据语义

1. 历史版本在编辑开始前保留旧内容，连续普通输入最多每 30 秒新增一个；批量替换、排版和恢复会强制检查点。历史不是无限保留，不能代替外部备份。
2. 自动备份存放在应用私有目录，卸载会删除。外部 .jzb 不含字体、主题／安全配置，也不是纯纯写作 .pwb 格式；不要互换两款软件的内部数据库。
3. 备份恢复采用合并：现有正文不变，导入文稿用新 ID。每日字数和写作时长默认不合并，可勾选按日期分别取较大值恢复，重复恢复不累加；速记追加保留。
4. 每日统计记录正文编辑的正向字数变化，含粘贴，删除不抵扣。1.4 起双编辑器的正常正文编辑计入每日新增量；导入、恢复、批量替换和自动排版不计入每日新增量。该值不是每日净增长或准确写作时间。
5. 查找替换作用于正文，排除废纸篓和只读文稿；单篇超过 10,000 处匹配会提示缩小范围。正则不支持替换捕获组展开，`$1` 等替换字符串按原文插入。
6. ZIP 不直接解压到文件系统；拒绝上级目录路径，最多检查 5,000 个条目、导入 1,000 篇，总解压 64 MB、单篇 2 MB。非文本附件不会导入。
7. 长图最多 16,000 px 高，PDF 最多 1,000 页，整库恢复文件最多 64 MB，字体导入最多 32 MB。超限会报告错误，原文稿不受影响。
8. PDF、PNG 默认按基础 Markdown 排版，也可选择保留标记的原文模式；HTML／DOCX／EPUB 按支持的 Markdown 子集排版，原始 HTML 转义为文字；图片、公式和复杂嵌套尚不渲染。Unicode 正文保存与 MD / TXT 导出不损失字符，但视觉导出中罕见字的显示取决于系统／自定义字体是否含字形；本机模拟器缺少 `𠀀` 字形。
9. TTS 依赖设备语音服务；设备密码锁控制应用访问，不对文稿文件加密。本轮未用设置过密码的设备走完真实认证，也未验证中文 TTS 的语音播放。
10. 本轮不发布 GitHub Release，不修改 Apple 端数据结构和源码。当前交付为本地可安装的 Android 1.10.0 调试 APK。

## 1.2.0 实现说明

- 历史差异用于查看，恢复操作仍走原有历史恢复流程。超过 1,000,000 个行组合的对比降为整块增删，避免长篇比较占用过多内存。
- 勾选替换在执行前检查正文快照、只读和删除状态；预览后发生变化则整批拒绝，不使用过期位置改写。替换按字面值执行。
- 多文件导入先读取全部候选，任何文件编码或容量检查失败，本次均不导入；顺序和改名只作用于新文稿。
- DOCX 使用 OOXML 包，EPUB 使用 EPUB 3 包；导出只包含正文，无外链资源下载。Markdown 图片仍作为文字保留。无效 XML 控制字符以替代字符表示，原始文稿不改写。
- 每日目标保存在设备设置，.jzb 不包含该设置；年度汇总完全来自已有每日记录，不推测过往写作天数。
- 格式依据：[W3C EPUB 3.3](https://www.w3.org/TR/epub-33/)、[Microsoft WordprocessingML](https://learn.microsoft.com/en-us/office/open-xml/word/structure-of-a-wordprocessingml-document)。快捷方式使用 [Android ShortcutManager](https://developer.android.com/reference/android/content/pm/ShortcutManager)。

## 1.3.0 实现说明

- 内部库格式升级到 3，可读取格式 1／2；旧文稿的卷名按手动章节顺序首次出现的位置迁移为独立 ID，旧备份可合并，空卷和卷顺序可通过 .jzb 往返保存。旧版简作不支持读取格式 3，请保留升级前备份。
- 分卷改名同步有效文稿与废纸篓引用；整卷移动保留分卷 ID、正文和历史，目标同名卷冲突在任何修改前拒绝。解散卷只移除组织关系。
- 批量编号按成书顺序生成完整计划，范围可为全本／未分卷／单卷，序号 1–1,000,000、补零位数 1–7。应用前再次检查文稿标题、只读和删除状态；预览过期整批拒绝。
- 标签以空白、逗号或分号分隔，忽略开头 #，精确匹配区分大小写；正文搜索行为保留。折叠与目录偏好仅存本机，备份不带界面偏好。

## 1.4.0 实现说明

- 第二编辑器使用两个原生输入区，沿用现有文稿模型和保存队列；没有复制出另一份内部正文。标题／正文变更保留历史，两个输入区都保护中文组合输入。
- 当前激活稿决定文稿菜单、快捷键和快捷输入目标；选稿排除另一侧已打开的文稿，防止同篇双视图互相覆盖。只读、废纸篓和损坏库写保护继续生效。
- 双稿占据完整写作区域，按窗口宽度选择左右／上下布局；返回关闭双稿，原列表导航保留。两篇分别记忆位置，联动使用滚动范围比例，不保证段落或语义一一对应。
- 在指定章前／后创建新章前验证原章仍有效；新章继承分卷／标签，原章即使只读也可作为位置参考，不改写原章正文。垃圾箱中的章节不能作为插入位置。
- 目录滚屏仅接受简作内部的章节拖动，在上下边缘持续滚动，离开／松手／取消即停。没有开放外部拖放写入。
- 本轮库格式仍为 3，.jzb 兼容 1.3.0，未新增运行时依赖或联网权限。

## 1.5.0 实现说明

- 快捷栏使用设备设置中的独立配置，保留各快捷项稳定 ID；同名标签不会混淆内容。先在副本中编辑，最终保存才写入，恢复默认布局不删除自定义内容。
- 内置操作仍调用原有编辑方法，保留选区包裹、只读和当前双稿保护。每行独立横向滚动，隐藏所有项目后仍可从菜单管理；排序菜单可到达屏幕外的位置。
- 字符按 Unicode 码点计数，不按 UTF-16 长度；不含空白同时排除 Unicode 空格，汉字包含补充平面汉字。选区计数只针对正在编辑的正文，不合并标题或 Markdown 预览片段；正向／反向选区均可恢复和使用快捷项，读屏包含实时计数。
- 状态栏口径不改变字数目标、每日新增量和目录统计的含义；这些统计继续使用原有混合字数。界面偏好不进入 .jzb，库格式仍为 3。

## 1.6.0 实现说明

- 写作时长独立于新增字数，标题或正文实际修改后启动，停笔最多计入 60 秒。离开前台、窗口失焦、界面重建与切换稿件暂停，再次修改才启动；双稿使用单个计时器。速记、导入与批量操作不启动计时，不能据此推测精确创作效率或过往时间。
- 每日详情、今日／累计、年度／月度均显示时长，年度列表包含只有时长的年份；新增天数及连续天数仍按字数计算。经过时间计量防止系统时间跳变产生虚增，本地日期负责跨午夜归属。
- 库格式 4 增加按日毫秒记录，校验实际日期、整型数值及范围；支持读取 1／2／3，不伪造旧时长。新库和新备份需要 1.6.0 或更新版，首次新保存前保留旧库快照。
- 统计恢复默认关闭，选择恢复时同日字数与时长各取最大值，避免反复恢复累加；不作为跨设备统计合计。记录开关是本机偏好，关闭不删历史记录。时长每 10 秒及修改、暂停时结算，强制结束进程可能失去最后尚未保存的一段。

## 1.8.0 扫描与找回完善

目录扫描新增进度、取消和数字自然排序；任务跨配置重建保留，取消后迟到结果不再进入预览。系统查询使用取消信号，读取中检查取消，后台最多两路，避免不响应的提供方无限增加线程。

「备份与恢复 → 按关键词找回文稿内容」搜索当前、废纸篓、历史和本机自动快照；相同文稿的相同标题／正文只显示一次，恢复为独立可编辑副本。单份快照 64 MB、总读取预算 256 MB、最多显示 200 个版本；损坏快照跳过并提示。没有整库覆盖或重复文稿自动合并，来源文件保持不变。

## 1.9.0 PDF 与长图排版

PDF／PNG 导出新增排版选择：默认基础 Markdown，支持标题、粗体、斜体、代码、带网址的链接、列表、任务、引用、分隔线及最多 8 列的基础表格；原文模式保留 Markdown 标记。PDF 按文字行分页，长表格重复合适高度的表头，超长单行表格按单元格行拆分，短单元格内容不重复。超过 8 列的表格按原文代码块输出，图片、公式、HTML 和复杂嵌套仍保留文字。

先在应用私有缓存中完成排版，再打开用户选择的目标文件；超限或排版失败不会提前清空已有文件，系统最终写入失败仍可能产生不完整文件。输出保留既有 A4、1080 px 长图和页数／高度限制，文稿正文与库格式 4 保持不变。

## 1.10.0 配色与稿纸完善

「写作设置」提供简作、山林、海雾、玫瑰、黑白五套内置配色，分别有深浅色版本，明暗模式沿用原来的跟随系统／浅色／深色选项。横线依据原生文本基线绘制，兼容自动换行、字号／行距、单稿／双稿、只读正文与空白输入区；Markdown 预览不显示横线。

设置窗口内先预览，点「完成」一起提交，取消不写偏好。保存后的主题、稿纸和选区跨界面重建及正常重开保留；未保存的设置窗口不跨旋转保留。主题／稿纸仅为本机设置，不修改正文、历史、统计、库格式及导出样式，不包含于 .jzb。自定义颜色、背景图片和主题文件互通仍未实现。


## 1.11.0 安卓中英文界面

新增简体中文、English 和跟随系统选择，完成界面文案资源化，并让菜单动作与翻译文字分离。系统筛选与快捷项采用稳定标识；用户命名、自定义插入内容、文稿与历史不因语言切换改写。Android 13+ 与原生应用语言设置一致，旧系统保存本机覆盖。语言选择不写入文稿备份；本轮不自动翻译文稿，也未完成其他语言、Apple 界面及 EPUB 语言元数据。


## 1.12.0 DeepSeek 主动续写

安卓新增「写作设置 → DeepSeek AI 设置」与「文稿菜单 → 写作工具 → AI 续写」。用户配置自己的 Key 和模型，生成前展示发送范围与费用，结果可编辑、复制、取消、重生成，再插入光标位置；文稿变化后禁止套用旧快照。Key 单独加密保存，不进入备份或安装包。用户提供的临时 Key 已用于生产请求代码和 Android 设备的中文／英文真实调用测试。此实现不包含竞品的其他 AI 工作流，详见 [使用说明](../Android/README.md) 与 [验证记录](Android-validation.md)。
