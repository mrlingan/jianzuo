# Apple 1.1.0 功能补齐与验证

2026-10-09。本轮在现有 SwiftUI 共享工程中，为 Mac、iPhone 与 iPad 补齐常用本地写作能力，参考 Android 1.1–1.10 的交互与数据保护方式。安卓工程未修改。

## 本轮已实现

| 功能 | 入口与行为 |
| --- | --- |
| 自定义笔记本 | 侧栏「我的笔记本」旁的文件夹按钮。创建、重命名、删除空笔记本；重命名包含废纸篓中的文稿。须保留至少一个笔记本。 |
| 标签与只读 | 编辑器「更多 → 编辑标签 / 设为只读」。标签去重并参与搜索，列表支持精确标签筛选；只读时禁止正文、标题与批量排版修改。 |
| 历史记录 | 「更多 → 历史记录」。编辑前留存旧内容，30 秒内合并自动快照，最近 40 份；手动保存版本、替换、排版及恢复前可强制快照。预览后恢复原稿或另存为新文稿。 |
| 校验备份 | 侧栏「备份与恢复」。导出 `.jzb`，SHA-256 校验完整内容后才允许合并；包含文稿、废纸篓、历史、笔记本、标签、只读状态、速记和每日字数。恢复分配新文稿 ID，保留现有文稿；统计按同日较大值合并，可选择不恢复统计。 |
| 本机自动备份 | 保存变化后的库之前保留上一份已保存内容，每分钟最多一份，保留最近 10 份。备份页可选择并查看恢复预览。仍位于本机，不能代替外部备份。 |
| 恢复搜索 | 在备份页按关键词查找当前文稿、废纸篓和历史，预览全文后另存为新文稿；最多展示 200 项。 |
| 查找替换 | 「更多 → 查找替换」。大小写选项、正则、匹配列表、勾选替换、点击匹配定位。替换文字按字面处理；正文变化时拒绝应用旧匹配。匹配上限 10,000，正则查找有耗时保护。 |
| 大纲定位 | 「更多 → 文稿大纲」。读取 1–6 级 Markdown 标题，跳过反引号和波浪线围栏中的代码；按原生 UTF-16 位置定位选区。 |
| 正文排版 | 「更多 → 正文排版」。清除缩进、段首两格、段间空行、去空行、中英空格。检查预览后应用，原稿保留在历史。 |
| 双稿编辑 | 「更多 → 第二编辑器」或文稿右键菜单。主副稿独立编辑、预览和保存；宽度足够时并排，比例 35–65% 且每栏至少 340 点；小窗口与手机使用切换栏。导出副稿保留主稿选择。 |
| 快捷输入 | 正文下方输入栏；「设置 → 配置快捷输入栏」支持隐藏、1–3 行、增删、拖动排序和多行内容。插入原生光标 / 选区，可原生撤销。切换预览后不会重复执行插入。 |
| 状态栏计数 | 点击字数切换中英文字数、全部字符、不含空白字符、中文字数；显示选区计数。窄栏优先保存状态与计数。 |
| 速记与每日写作 | 侧栏入口。速记自动保存并可创建文稿；每日目标、近期字数与今年累计。正文输入的正向字数增长计入，删除不扣减；粘贴计入，导入、恢复和批量工具不计入。 |
| 多文件导入预览 | 现有导入入口先展示 UTF-8 文件预览，支持勾选、改标题、调整顺序、数字自然排序和选择笔记本；确认前不写入库，确认后清除旧搜索与标签筛选。 |
| 五套配色与稿纸 | 设置中的经典、林间、海雾、蔷薇、黑白；可预览深浅色与横线稿纸，点击「完成」才保存这三类外观设置。稿纸随原生文本实际行绘制，不更改正文。 |

## 数据兼容

- 旧 Apple v1 库自动读取，首次保存升级为 v2；旧文稿 ID、正文、笔记本、收藏和时间保持不变。
- v2 增加自定义笔记本、每日字数、速记，以及文稿标签、只读和历史字段。旧版 Apple 1.0 不支持新库，请保留外部备份后再升级。
- 读取失败或未知库版本时禁止覆盖原文件，也禁止创建 / 导入导致无法保存的文稿。
- Apple `.jzb` 格式标识为 `jianzuo-apple-backup`，与安卓 `.jzb` 的数据模型不同，暂不互相导入。跨平台继续使用 Markdown / TXT；Apple 设备之间可交换完整备份，无自动云同步。
- 字体、配色、快捷输入等设备设置保存在 UserDefaults，不包含在文稿库备份中。

## 验证结果

- Xcode 27.0：Mac Debug 构建及 **15 项单元测试全部通过**（原有 6 项，新增 9 项）。
- iOS Simulator Debug 与 iOS 真机目标 Release 未签名构建通过，目标覆盖 iPhone 与 iPad；最低部署版本继续为 iOS / iPadOS 17、macOS 14。
- Mac 实际界面检查使用独立 `/tmp/jianzuo-apple-ui-check/library.json` 示例库：双稿选稿、独立预览、快捷输入替换选区、原生撤销、返回编辑不重复插入、两处匹配仅勾选一处替换，以及深色林间稿纸、本机自动备份校验后的恢复预览均已检查。侧栏设置固定在底部，窄栏状态信息已精简。
- 2026-10-09：在 iPhone 18 Pro / iOS 27 模拟器复现并修复启动黑屏。正文编辑器传入未连接布局管理器的文本容器，触发 `text container must already have a layout manager` 异常；现由 UIKit 完整创建 TextKit 1 排版组件。
- 修复后 iOS Debug 构建通过，**16 项 iOS 测试全部通过**，新增测试覆盖原生编辑器创建、中文和表情输入、稿纸绘制。已通过用户当前 Xcode 的 Run 操作确认编辑页正常显示，原有文稿和设置文件保持不变。日志、测试结果和截图位于 `Build/iOS-startup-fix/`。
- 键盘避让、旋转、iPad 运行和真机安装尚未完成验证。
- 构建只有系统 AppIntents 元数据提取提示，无 Swift 编译警告。`git diff --check` 与 Info.plist 检查通过。

复现命令：

```sh
xcodebuild -project Jianzuo.xcodeproj -scheme Jianzuo \
  -destination 'platform=macOS' -derivedDataPath Build/AppleParity-Mac \
  CODE_SIGNING_ALLOWED=NO test

xcodebuild -project Jianzuo.xcodeproj -scheme Jianzuo \
  -sdk iphonesimulator -destination 'generic/platform=iOS Simulator' \
  -derivedDataPath Build/AppleParity-iOS CODE_SIGNING_ALLOWED=NO build

xcodebuild -project Jianzuo.xcodeproj -scheme Jianzuo \
  -sdk iphoneos -destination 'generic/platform=iOS' -configuration Release \
  -derivedDataPath Build/AppleParity-iOS CODE_SIGNING_ALLOWED=NO build
```

Debug 版可使用 `JIANZUO_LIBRARY_PATH` 指定独立测试库，避免用个人文稿进行界面验证；Release 忽略该变量。共享 Scheme 为测试宿主配置独立路径 `/tmp/jianzuo-xctest-host/library.json`，单元测试各自使用独立临时目录。

## 与安卓仍有差距

以下功能未在本轮实现，不应将 Apple 1.1.0 视为 Android 1.10 的完整等价版本：

- 独立分卷、空卷、目录折叠、章节拖动和批量编号、整卷移动 / 回收。
- 双稿联动滚动，以及跨重启保存光标、滚动位置和双稿选择。
- 历史差异对比、段落移动、自动写作时长、年度热力图及月度汇总。
- 文件夹递归扫描、扫描进度 / 取消、系统分享文本接收和本机自动备份内部的全文搜索。
- PDF / PNG / HTML / ZIP / DOCX / EPUB 导出、成书导出、富文本复制。
- Markdown 图片、表格和 HTML 渲染，云同步与 AI。
