# 简作 v1.0.0

简作的第一个开源版本：一个支持 Mac、iPhone 和 iPad 的原生 SwiftUI 写作空间。

## 下载和安装

| 文件 | 用途 |
| --- | --- |
| `Jianzuo-1.0.0-macOS-universal.dmg` | Mac 安装包，打开后将「简作.app」拖到 Applications |
| `Jianzuo-1.0.0-macOS-universal.zip` | Mac 应用压缩包，解压后将 App 移到 Applications |
| `Jianzuo-1.0.0-iOS-Simulator.zip` | 开发者用 iPhone / iPad 模拟器包，**不能安装到真机** |
| `Jianzuo-1.0.0-iOS-unsigned.ipa` | arm64 真机 IPA，源码直接构建、未加密、未签名，安装前需要自行签名 |
| `Jianzuo-1.0.0-iOS-unsigned.ipa.sha256` | 真机 IPA 的 SHA-256 校验值 |
| `SHA256SUMS.txt` | Mac DMG / ZIP 和 iOS 模拟器 ZIP 的 SHA-256 校验值 |

Mac 包包含 **arm64 和 x86_64** 两种架构，最低要求 **macOS 14**。

Mac 包使用 ad-hoc 签名，**没有 Developer ID 签名和 Apple 公证**。首次运行可能显示 macOS 安全提示，请核实下载来源并按系统提示操作。

iPhone / iPad 真机 IPA 使用 iPhoneOS SDK 从本项目源码直接构建，不包含 App Store FairPlay 加密或第三方加壳。此包**未签名**，没有描述文件，不能直接在普通真机上安装；请先使用自己的有效证书和描述文件重新签名。也可以下载源代码，在 Xcode 中选择自己的开发团队后运行到设备。最低 iOS / iPadOS 17。

## 功能

- 文稿、灵感、日记笔记本；标题与全文搜索。
- 原生编辑器和本地自动保存。
- Markdown 预览、Markdown / TXT 导入导出。
- 收藏、文稿副本、废纸篓与恢复。
- 专注模式、字体与行距设置、浅色 / 深色外观。
- 中英文字数统计、阅读时间和每篇文稿字数目标。

各设备独立保存文稿，本版尚未包含 iCloud 同步。Markdown 预览暂不渲染图片、表格和 HTML。

## 模拟器安装（开发者）

解压 `Jianzuo-1.0.0-iOS-Simulator.zip`，启动 Xcode 中的 iPhone / iPad 模拟器，然后在解压目录运行：

```sh
xcrun simctl install booted Jianzuo.app
xcrun simctl launch booted com.jianzuo.writing
```

本次模拟器包使用 iOS 27 SDK 构建，已在 iOS / iPadOS 27 模拟器验证。其他运行时版本请从源代码构建。

真机 IPA 使用 iOS 27 SDK 构建，尚未在真实 iPhone / iPad 上安装验证。
